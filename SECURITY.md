# Security Policy

## Supported Versions

NetWeevil is pre-1.0; only the latest `main` receives fixes.

## Reporting a Vulnerability

Please do not open public issues for security vulnerabilities. Instead, use
GitHub's private vulnerability reporting ("Report a vulnerability" under the
Security tab) so the report reaches the maintainers privately.

Include what you can: affected component (CLI, HTTP API, QGIS plugin,
ingest), a reproduction, and the impact you believe it has. The HTTP API is
designed for local/trusted-network use; reports about exposing it to
untrusted networks are still welcome, since deployments do so in practice.

You should receive an acknowledgement within a week. Coordinated disclosure
is appreciated — we will credit reporters in the release notes unless you
prefer otherwise.
